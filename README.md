Iris Flower Data Acquisition and Pre-processing

Project Overview

This project demonstrates a complete data acquisition and preprocessing pipeline using Python.

Dataset

The Iris Flower Dataset is used for this project. It contains 150 observations, four numerical features, and three flower species.

Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

Project Workflow

1. Data acquisition
2. Data inspection
3. Missing value handling
4. Duplicate removal
5. Outlier detection using IQR
6. Data scaling using StandardScaler and MinMaxScaler
7. Feature selection using SelectKBest
8. Data visualization
9. Exporting cleaned dataset

Project Files

* week1_iris_preprocessing.py – Python source code
* iris_raw.csv – Original dataset
* iris_cleaned.csv – Processed dataset
* iris_pairplot.png – Data visualization
* Week1_Data_Acquisition_Preprocessing_Report.docx – Project report

How to Run

Install the required libraries:

pip install pandas numpy scikit-learn matplotlib

Run the project:

python week1_iris_preprocessing.py

Learning Outcomes

This project helped in understanding data acquisition, data cleaning, preprocessing, feature scaling, feature selection, and visualization using Python.
